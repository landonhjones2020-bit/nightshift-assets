# nightshift-assets

Asset hand-off repository for **Night Shift at STACKHOUSE** (Roblox).
Every model and animation here is generated by Python scripts running Blender headless.

| Folder | Contents |
|---|---|
| `blender/lib/nslib.py` | Shared modelling, export, preview and animation library |
| `blender/<batch>/<Asset>.py` | One re-runnable generator per asset (`NS_EXPORT=1` to export) |
| `meshes/<batch>/<Asset>.json` | Mesh data in Roblox axes and studs (Path A import) |
| `fbx/<batch>/<Asset>.fbx` | The same assets as FBX (Path B import) |
| `manifests/<batch>.json` | Per-asset part colours, materials, roles and bones |
| `anim/<Rig>.lua` | Blender keyframes for the in-game `BlenderAnimator` |
| `icons/<group>/<Name>.png` | 512 px icon renders |
| `studio-plugin/` | The local Studio plugin that publishes meshes from this repo |

Conventions: 1 Blender unit = 1 stud; assets face Blender −Y (Roblox LookVector);
pivots at bottom-centre (hinges for doors/lids). Nothing secret belongs in this repo.
